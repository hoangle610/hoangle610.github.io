Privacy Policy

Quiz Solver AI — Last updated: September 2026

1. Overview

Quiz Solver AI is a Chrome extension that helps users solve multiple-choice quizzes using Google's Gemini AI. We are committed to protecting your privacy and being transparent about our data practices.

2. Data Collection

This extension collects and processes the following data locally on your device only:

  • Gemini API Key — stored in Chrome's local storage on your device. Never transmitted to any server other than Google's Gemini API.
  • Quiz content — question text and answer options scraped from the active page. This data is sent to Google's Gemini API for processing and is not stored or logged by the extension.
  • User preferences — model selection, auto-click, and auto-submit settings stored in Chrome's local storage.

3. Data Storage

All data is stored locally using Chrome's chrome.storage.local API. No data is transmitted to any third-party servers, databases, or analytics services operated by the extension developer.

4. Third-Party Services

This extension communicates with Google's Generative AI API (Gemini) to process quiz questions. Data sent to this API is subject to Google's Gemini API Terms of Service and Google's Privacy Policy.

5. Permissions Explained

  • activeTab — Access the content of the currently active tab to scrape quiz questions.
  • storage — Save your API key and preferences locally.
  • scripting — Inject scripts to detect and highlight quiz answers on web pages.
  • webNavigation — Access iframe contents to find quizzes embedded in sub-frames.
  • host_permissions (<all_urls>) — Required to operate on any quiz platform, as quizzes can be hosted on any domain.

6. Data Sharing

We do not sell, share, or transfer your data to any third parties for any purpose other than the core functionality described above (sending quiz data to Google's Gemini API for solving).

7. Security

Your API key is stored only in Chrome's secure local storage and is transmitted only via HTTPS to Google's API endpoints. The extension does not log, cache, or persist any quiz data after processing.

8. Children's Privacy

This extension is not directed at children under 13 years of age. We do not knowingly collect personal information from children.

9. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be reflected in the "Last updated" date above and in updated versions of the extension.

10. Contact

If you have questions about this privacy policy, please contact the developer through the Chrome Web Store listing.
